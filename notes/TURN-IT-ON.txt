TURNING THE LINE BOT ON — six steps, all of them yours
Built 2026-09-07.  The Worker is deployed and waiting; it cannot listen until
LINE has a webhook address and the Worker has LINE's two secrets.

Webhook address to paste:   https://line.motdang.net/line/webhook

Everything below happens in two consoles: LINE OA Manager (manager.line.biz),
which is the account, and LINE Developers (developers.line.biz), which is the
Messaging API channel behind it. The account is @964yxgnk — the same Mot Dang
Official Account the site's contribute links already point at.


1.  TURN ON THE MESSAGING API
    OA Manager -> Settings -> Messaging API -> Enable.
    It asks for a provider; any of yours will do. This creates the channel that
    the Developers console then shows you.

2.  POINT IT AT THE WORKER
    Developers console -> that channel -> Messaging API tab.
    Webhook URL:  https://line.motdang.net/line/webhook
    Turn "Use webhook" on, then press Verify.

    Verify should come back Success. If it says anything else, stop at this
    step and tell me what it said — everything after this depends on it.

3.  COPY THE TWO SECRETS
    Basic settings tab   -> Channel secret
    Messaging API tab    -> Channel access token (long-lived) -> Issue

    The token can send messages as the account, so it never goes in a repo and
    I never handle it. Put both in your keys file:

      open ~/.config/nanobotco/keys.json

    and add, alongside the other entries:

      "line": { "channel_secret": "...", "channel_token": "..." }

    then:

      cd "/Users/annikapeacock/Desktop/claude code projects/motdang-line"
      ./deploy.sh

    It picks both up and sets them on the Worker. Nothing else changes.

4.  LET IT INTO GROUP CHATS
    OA Manager -> Settings -> Account settings.
    Allow the account to join group chats and multi-person chats.

    While you are there, look at Response settings. Your readers' one-to-one
    messages are answered by whatever is set there now, and the bot does not
    touch them — it ignores every one-to-one message on purpose, so nobody
    writing to Mot Dang gets two answers.

5.  INVITE IT TO THE TEAM GROUP
    Add @964yxgnk to the Mot Dang group the way you would add a person.

    The first group it is added to becomes the team group and the only one it
    ever works in. It says hello with what it does. If it ends up in the wrong
    group first, tell me and I will clear the one line that remembers it.

6.  CHECK IT, IN THE CHAT
    Type:  status
    It should answer with what it is holding — zero of everything, on day one.
    Then send a photo and say a place name. It should either say what it filed
    the photo under, or ask which place.
